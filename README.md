# 🧠 NeuroQuiz

A mobile-friendly quiz app for medical students to master neuroanatomy — myotomes, dermatomes, nerve motor innervation, and brain regions.

Built with React, TypeScript, and Vite. Uses active recall, gamification, and study mode to help users learn and retain anatomical relationships.

## Features

- **101 questions** across 4 categories with 60+ custom anatomy illustrations
- **Timed Quiz Mode** — 60-second sprint with instant visual feedback
- **Study Mode** — untimed, with explanation cards and manual advance
- **Multi-select** — nerve motor questions support selecting multiple correct actions
- **Practice Missed** — drill only the questions you got wrong
- **Configurable** — direction (forward/reverse/alternating), display mode (text/image/combined)
- **Admin Panel** — password-protected asset editor for managing questions and images (local dev only)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

- React 19 + TypeScript
- Vite 6
- Tailwind CSS v4
